# Welcome to Vellum

Vellum is a workspace for documents, books, structured data, issue
tracking and personal tasks. Every page you write is a plain Markdown
file in a real folder, so your work stays readable without Vellum and
outlives any one tool.

This is the **user guide**. It teaches you to write, organise and share
work in Vellum. Two other books cover the rest:

- The [admin guide](../admin.book/README.md) covers installing,
  securing, backing up and running Vellum.
- The [developer guide](../developer.book/README.md) covers the
  architecture, the API, the Markdown dialect grammar and how to
  contribute.

::: cards

- 🚀 **Start here** Your first page, the slash menu, sharing and export in ten minutes.
- ✍️ **Writing** Every block with the Markdown that makes it.
- 📊 **Data** Collections with relations, rollups and formulas.
- 📘 **Books** Documents made of documents, numbered and exportable.
- ✅ **Work and My Work** Issues, cycles, triage and your own task list.
- 🤖 **AI and MCP** Let Claude read, search and draft under your permissions.

:::

## How to read this guide

Every block in the [Writing](writing/README.md) and
[Diagrams](diagrams/README.md) parts appears twice: first as Vellum
shows it, then as the Markdown you type. Copy the Markdown into any page
to get the same block.

The examples use **Northstar**, a fictional company that builds an API
gateway. You will meet its people throughout:

::: facts

- Priya Shah: product lead, owns the roadmap
- Dev Rao: engineer on the gateway team (ENG)
- Maya Kim: designer
- Sam Ortiz: operations and on-call (OPS)
- Lena Fischer: workspace admin

:::

::: tip
Press `?` anywhere in Vellum to open the page of this guide for the
screen you are on. Run `vellum docs` to read the guide offline.
:::
