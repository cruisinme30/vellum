# Keyboard shortcuts

Press `?` anywhere to see every shortcut for the screen you are on. On
Windows and Linux, read `⌘` as `Ctrl` and `⌥` as `Alt`.

## Everywhere {#global}

| Keys | Action |
| --- | --- |
| `⌘K` | Find a page by title, or run any command |
| `C` | New issue |
| `Alt C` | New issue from a template |
| `Q` | Quick-add a task |
| `G` then `I` | Go to Inbox |
| `G` then `M` | Go to My Work |
| `G` then `B` | Go to the board |
| `G` then `C` | Go to the current cycle |
| `G` then `T` | Go to triage |
| `?` | Show all shortcuts |

## In the editor {#editor}

| Keys | Action |
| --- | --- |
| `/` | Insert any block (on an empty line) |
| `⌘B` `⌘I` `⌘E` | Bold, italic, inline code |
| `⌘⇧K` | Link |
| `Tab` `⇧Tab` | Indent, outdent |
| `⌘↵` | Toggle a task |
| `⌘⌥M` | Comment on the selection |
| `T` | Turn the selection into a task |

Markdown shortcuts work as you type: `#`, `-`, `[]`, `>`, three
backticks, `:::` and `|`.

## In issue lists {#issues}

| Keys | Action |
| --- | --- |
| `S` | Set status |
| `P` | Set priority |
| `L` | Set labels |
| `A` | Assign |
| `I` | Assign to me |
| `E` | Set estimate |
| `⇧C` | Set cycle |
| `X` | Select for bulk changes |
| `Space` | Peek without opening |
| `⌘⇧.` | Copy the Git branch name |
