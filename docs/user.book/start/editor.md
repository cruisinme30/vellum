# The editor

The editor is where you spend most of your time. It shows rich blocks,
but every keystroke edits a Vellum Markdown file underneath.

## The screen {#layout}

::: columns

**Navigation rail**
New, Home, Search, Favorites, Inbox, Data, Theme, Help and Admin. On a
phone the rail becomes a bottom bar.

---

**Sidebar**
The page tree of the drive you are in. Drag pages to reorder or nest
them; the `⋯` menu on each row moves, copies, shares or deletes.

---

**Page**
The title, the body and, on the right, comments and the outline.

:::

## Blocks {#blocks}

A page is a list of blocks: paragraphs, headings, lists, callouts,
charts, diagrams and the rest. Hover a block to see its handle. Drag the
handle to move the block; select it to open the block menu, where you
can turn the block into another type, copy a link to it or open its
settings.

Block settings show the block's attributes: its ID, classes and options
such as a chart's height. They are the same attributes you can type in
Markdown, for example `{#rollback .wide}`.

## Comments and suggestions {#comments}

Select text and press `⌘⌥M` to comment. Mention someone with `@` to
send them an inbox item. Switch the page to **Suggesting** to propose
changes that the page owner accepts or rejects one by one.

## Page status and verification {#status}

Every page has a status: draft, in review, verified or outdated. A
verified page can ask to be checked again after a period, such as every
90 days. When the period runs out, the page owner gets a task and the
page shows as outdated until someone verifies it again.

## Versions {#versions}

Open **⋯ → Version history** to see every saved version, who made it
and what changed. Select a version to compare it with the current page,
then **Restore** to bring it back. Restoring creates a new version; it
never deletes history.

## Themes {#themes}

Select **Theme** in the navigation rail to switch between Light, Dark,
High contrast, Sepia and Dim, or to build a theme from a seed colour.
Charts and diagrams follow the theme. Reduced motion, density and a
dyslexia-friendly font are in the same panel.
