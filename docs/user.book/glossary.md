# Glossary

| Term | Meaning |
| --- | --- |
| Block | One unit of a page: a paragraph, heading, list, callout, chart and so on. |
| Book | A document made of pages, ordered by a `SUMMARY.md` file. |
| Collection | A database whose rows are pages, stored as a folder. |
| Container | A block that starts with `:::` and wraps other blocks. |
| Cycle | A team's fixed working period, such as two weeks. |
| Draft | A change written by a model or proposed by a person that waits for review. |
| Fence | A block between three backticks, such as a chart or a diagram. |
| MCP | Model Context Protocol, the standard way AI clients connect to tools such as Vellum. |
| My Work | The list of everything assigned to you. |
| Shared drive | A top-level folder that a team owns together. |
| ULID | The 26-character identifier every page, row and issue has. |
| Vellum Markdown | The Markdown dialect Vellum pages are written in. |
