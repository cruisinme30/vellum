# Cookbook

Twelve recipes, from a five-minute meeting note to a docs pipeline
built on Git. Each one says what you will build, walks through it step
by step and ends with the finished Markdown, which you can paste into a
page to start from.

| # | Recipe | Uses | Time |
| --- | --- | --- | --- |
| 1 | [Meeting notes with action items](meeting-notes.md) | Tasks, mentions, dates | 5 min |
| 2 | [A personal task list](personal-tasks.md) | My Work, quick-add, recurrence | 10 min |
| 3 | [A weekly status page](status-page.md) | Stats, charts, callouts | 15 min |
| 4 | [A requirements tracker](requirements-tracker.md) | Collections, formulas, views | 20 min |
| 5 | [Running a cycle](running-a-cycle.md) | Issues, triage, cycles | 20 min |
| 6 | [Exporting a chapter as PDF](export-chapter.md) | Books, export | 10 min |
| 7 | [A PRD with live issue chips](prd-with-issues.md) | Issues in pages, roadmap, risk | 30 min |
| 8 | [An on-call runbook with a calculator](on-call-runbook.md) | Steps, calculator, Mermaid | 30 min |
| 9 | [A quarterly review book](quarterly-review.md) | Books, collections, live charts | 45 min |
| 10 | [Release notes from an MCP prompt](release-notes-mcp.md) | MCP, drafts, review | 20 min |
| 11 | [A private research wiki](private-research-wiki.md) | End-to-end encrypted spaces | 30 min |
| 12 | [Docs as code with Git and mdBook](docs-as-code.md) | Git Sync, books, publishing | 45 min |
