# Exporting a chapter as PDF

**You will** export one chapter of the engineering handbook as a PDF
with its own table of contents and working cross-references.

## Steps

1. Open the handbook and select the chapter "Architecture".
2. Open **⋯ → Export → PDF**.
3. Choose **This section and its children**.
4. Pick the **print** profile for page numbers and running heads, or **screen**
   for a PDF that looks like the page.
5. Select **Export**.

The chapter's sections become 1, 1.1 and 1.2 in the PDF, its headings
start at the top level, and a link to a section outside the chapter
reads "see §3.2 Deploys in the Engineering handbook".

::: tip
Export the whole book from its first page with **Whole book**. The PDF
then has a cover and a table of contents with page numbers.
:::
