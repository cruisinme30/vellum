The workspace that lives in your folders.

Documents, books, databases, issue tracking, tasks and a drive in one small binary. Every object is a Markdown file you can open, grep, back up and put in Git. The database is only an index you can rebuild.

Get started View the source

Vellum is in active development toward its 1.0 release. Follow along on GitHub.

Your files, not our format

A page is a .md file. A book is a folder with a SUMMARY.md that builds with unmodified mdBook. A collection is a folder with one page per row. Edit them in Vellum, in your editor or with a script, and Vellum notices and merges the change.

Stop the server and your workspace is still there: readable, searchable and yours. 

northstar/
├─ drives/shared/product/
│  ├─ roadmap.md
│  ├─ handbook.book/
│  │  ├─ book.yaml
│  │  ├─ SUMMARY.md
│  │  └─ welcome.md
│  └─ customers.collection/
│     ├─ schema.yaml
│     └─ rows/acme.md
├─ teams/NS/issues/NS-142.md
└─ tasks/ana/inbox.md

One workspace instead of six tools

  • Pages and real-time editing

    A block editor with comments, history and live collaboration, exporting to PDF, Word, HTML and Markdown.

  • Books

    Long documents as a tree of pages with numbering, cross-references and whole-book export. Publish one as a static site.

  • Collections

    Databases with typed properties, relations and formulas, shown as tables, boards, calendars and galleries.

  • Work

    Fast issue tracking with cycles, triage, projects and Git automation, keyboard first.

  • My Work

    Your personal tasks next to the issues assigned to you, with reminders and a daily digest.

  • Drive

    Spaces, folders, favourites and sharing that organise all of it, with attachments stored where you choose.

  • An AI door, on your terms

    A built-in MCP server lets Claude and other models search, read and draft with your permissions. Their edits arrive as drafts for you to accept.

  • Encrypted by default

    Every document is encrypted at rest with its own key. Private spaces can be end-to-end encrypted.

  • Laptop to organisation

    One binary idles under 80 MB on a laptop and scales out to a highly available cluster with the same code.

Install

Vellum 1.0 will ship as a single signed binary, a container image and a Helm chart. Until then, build it from source. You need Rust (the pinned version installs itself), Node 22 and pnpm 10. 

git clone https://github.com/cruisinme30/vellum
cd vellum
cargo build --release
pnpm --dir web install

The contributing guide explains the branches and the checks every change passes.
